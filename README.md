# Интерьерная мастерская

Самостоятельный демонстрационный каталог мебели и интерьерных изделий. Проект показывает каталог, сравнение материалов, предварительный расчёт и сохранение обращения в отдельную PostgreSQL-БД.

Все ассортимент и тарифы являются демонстрационными. Не вводите реальные контактные данные в локальной демонстрации.

## Запуск

1. Создайте локальный файл окружения из примера и задайте локальный пароль PostgreSQL:
   `cp .env.example .env`
2. Установите зависимости: `npm --prefix frontend install`.
3. Поднимите отдельную БД `interior_demo`: `docker compose up -d postgres`.
4. Экспортируйте значения окружения из `.env`: `set -a; source .env; set +a`.
5. Запустите API: `npm run backend:run` (скрипт читает локальный `.env`; миграция применится при старте; API слушает `http://localhost:5080`).
6. В другом терминале запустите интерфейс: `npm run frontend:dev`.

Проверки: `npm run verify`. Для ручной сквозной проверки откройте `http://127.0.0.1:5174`, выберите материал, добавьте изделие к сравнению, перейдите к расчёту и сохраните демонстрационное обращение.
